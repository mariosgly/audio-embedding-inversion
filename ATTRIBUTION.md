1. Preserve the original license and copyright notice.
2. Clearly state that the work is derived from the upstream project.
3. Identify the upstream repository and, when possible, the upstream commit.
4. Mark substantive local additions and modifications.
5. Avoid presenting the derivative repository as an official upstream release.
